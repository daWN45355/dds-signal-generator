## 1 测试条件

| 项目 | 内容 |
|---|---|
| 板卡 | EBAZ4205 核心板（XC7Z010）+ hellofpga 扩展板 |
| 比特流 | `bitstream/7_key_dds.bit`（对应 `dds_key_top`，WNS +3.089 ns） |
| DAC 模块 | TLV5618A 双通道，基准 REF3030（3.0 V），供电 5 V |
| 接口 | SPI 三线（DIN/SCLK/CS）接 F19/F20/D19；串口接 CH340（D18/D20） |
| 示波器 | 双通道数字存储示波器，10× 探头，DC 耦合 |
| 上位机 | Windows 10 + Python 3，CH340 虚拟串口 |
| 环境 | 实验室常温，无屏蔽箱 |

**比对方法**：每一项都先由设计参数算出**理论值**（公式写在表前，可复算），
再与示波器读数或串口回传的**实测值**比对，给出偏差与判定。

需要先说清测量精度：示波器时基与幅度档位的读数精度决定了偏差的下限。
对周期类测量，本表按"时基 ±(0.01% + 1 个最低位)"估算，
即 1 ms 量级的读数分辨力约 1 μs；对电压类测量只比对**相对比例**，
因为绝对电压值取决于 DAC 基准与模块供电的实际值，本次未做万用表级标定。

## 2 频率比对

理论周期：`T = 1 / f`，f 由频率字 `freq_word = f × 85.89934592` 生成。
频率量化步长为 `50 MHz / 2³² = 0.0116 Hz`，即在 20 kHz 处的量化误差上限 0.0116 Hz，
相对误差 5.8×10⁻⁷，远小于示波器精度，故理论值可直接取设定值。

| 设定 | 理论周期 | 示波器读数 | 偏差 | 说明 | 判定 |
|---|---|---|---|---|---|
| F100 | 10.000 ms | 10.00 ms | < 0.1%（不可分辨） | 时基 2 ms/div，跨 5 格 | 通过 |
| F1000 | 1.000 ms | 1.000 ms | < 0.1% | 时基 200 μs/div，跨 5 格 | 通过 |
| F5000 | 200.0 μs | 200 μs | < 0.5% | 时基 50 μs/div | 通过 |
| F10000 | 100.0 μs | 100 μs | < 0.5% | 时基 20 μs/div | 通过 |
| F20000 | 50.00 μs | 50.0 μs | < 1% | 时基 10 μs/div | 通过 |

结论：频率换算链路（串口指令 → `freq_word` → 相位累加 → DAC 更新）正确。
若频率字公式错（例如少乘 2³² 或除法写成整数除法），1 kHz 会偏成 0 Hz 或数量级错误，
这种错误不可能藏在示波器精度里，因此该项比对是有效的。

## 3 波形形态比对

| 波形 | 指令 | 理论特征 | 实测观感 | 判定 |
|---|---|---|---|---|
| 正弦 | `W0` | 1024 点查表，中心 2048，平滑无断点 | 光滑正弦，无跳变、无平台 | 通过 |
| 方波 | `W1` | 取 `phase[31]`，占空比严格 50% | 上下沿陡直，占空比目视 50% | 通过 |
| 三角 | `W2` | `phase[31] ? ~phase[30:19] : phase[30:19]`，线性上升/下降各半周期 | 对称三角，峰谷尖锐 | 通过 |
| 锯齿 | `W3` | 取 `phase[31:20]`，线性上升后瞬间回落 | 斜升 + 垂直回落 | 通过 |
| 自动轮换 | `W4` | 每 2 s 换一种（`WAVE_PERIOD = 100_000_000`） | 约 2 s 换一次，循环 | 通过 |

锯齿波在早期版本上"不太完美"—— 回落沿有可见倾斜。原因是回落发生在相邻两个采样点之间，
而示波器在 20 kHz 时水平方向每格点数有限，视觉上被拉宽。这属于显示观感，
不是波形错误：把频率降到 1 kHz 后回落沿明显变陡，可反证这一点。

## 4 相位比对

理论：`phase_word = deg × 11930464`，B 通道相位超前 A 通道 `phase_word`（32 位满量程 = 360°）。

| 设定 | 理论相位差 | 实测（双迹观察） | 判定 |
|---|---|---|---|
| P0 | 0° | 两迹完全重合 | 通过 |
| P90 | 90° | 相差 1/4 周期（1 kHz 下 250 μs） | 通过 |
| P180 | 180° | 反相 | 通过 |
| P270 | 270° | 相差 3/4 周期 | 通过 |
| P359 | 359° | 接近重合但不等 | 通过 |

**相位稳定性**：设 P90 后静置观察 10 分钟，两迹相对位置无可见变化。
这一点是结构保证的：相位差由数字寄存器决定，不经过任何模拟移相网络，
两路数据在同一帧内同步生效，因此不随温度、供电、老化漂移。

**相位时差为零的机理**：TLV5618A 支持"写 BUFFER + 写 A 并同步更新 B"的双缓冲模式。
本设计每轮先发 `R1R0=01` 帧把 B 的值放进 BUFFER，再发 `R1R0=10` 帧写 A 并触发 B 从 BUFFER 重载。
两路 DAC 在**同一条 SCLK 上升沿**生效，时差在结构上为零，不靠"速度足够快"来压小。

**如实声明**：本次无相位计，上述结论基于双迹目视与长时间稳定性观察，
未做相位噪声、相位精度（角秒级）的量化测量，因此不声称这些指标。

## 5 幅度比对

理论：数字缩放 `code' = (code − 2048) × (pct × 655 >> 16) + 2048`，
即输出摆幅与百分比成正比，且直流中心保持在 2048（中点）不变。

| 设定 | 理论峰峰值（相对满幅） | 实测 | 判定 |
|---|---|---|---|
| A100 | 1.00 × 满幅 | 满幅 | 通过 |
| A50 | 0.50 × 满幅 | 约为满幅一半 | 通过 |
| A10 | 0.10 × 满幅 | 约为满幅 1/10 | 通过 |
| A1 | 0.01 × 满幅 | 极小，可见 | 通过 |

比对的是**比例**而非绝对电压。理由：绝对峰峰值 = `2 × Vref × (摆幅码/4096)`，
其中 Vref 由模块上的 REF3030 提供（标称 3.0 V，实际有 ±0.2% 初始误差与温漂），
模块供电与运放摆幅也会限制输出范围。未做万用表标定的情况下声称绝对电压值是不严谨的。

比对的**关键点**是"直流中心不随幅度移动"—— 若缩放公式少了 `+2048`，
波形会以 0 V 为轴缩放，示波器上表现为波形整体向下平移，A10 时几乎贴底。
实测各档位直流中心一致，说明公式实现正确。

## 6 20 kHz 台阶的定量比对

这是本次最值得记录的"实测值与理论值不一致"的一处，也是唯一一处。

### 6.1 理论每周期点数

采样率由 SPI 帧长决定：一轮双通道更新 144 个时钟，
`fs = 50 MHz / 144 = 347.22 kSPS`。

| 频率 | 理论每周期点数 | 实测台阶 | 判定 |
|---|---|---|---|
| 100 Hz | 3472 | 无可见台阶 | 一致 |
| 1 kHz | 347 | 无可见台阶 | 一致 |
| 5 kHz | 69 | 极难看出 | 一致 |
| 10 kHz | 35 | 仔细观察可辨 | 一致 |
| 20 kHz | **17.36** | **明显阶梯** | **一致（但波形不理想）** |

### 6.2 为什么 20 kHz 一定有台阶

DAC 在每个采样点之间保持前一个值不变，这叫零阶保持（Zero-Order Hold）。
每周期只有 17 个点，每个点被"保持"了 1/17 周期，于是波形由 17 段水平线组成。
这不是程序缺陷：商业函数发生器在高频仍光滑，是因为其内部采样率可达 100 MSPS 以上，
每周期有数千个点。本设计的采样率受限于 SPI 帧长（12.5 MHz SCLK × 16 位 × 2 通道）。

### 6.3 理论 vs 实测的偏差分析

理论每周期点数 17.36 不是整数，这一"不整"带来两个可预测的现象：

**（1）幅度读数抖动 ±1.63%**

相邻周期的采样点相对波形缓慢移动，每周期移动 0.36 个采样间隔。
采样点偏离峰顶的最大角度为
`0.5 / 17.36 × 360° ≈ 10.4°`，
于是峰值采样值比真峰值低 `1 − cos(10.4°) ≈ 1.63%`。

实测：20 kHz 时示波器的幅度读数确实在一个小范围内周期性浮动，幅度约 ±1.5%，
与理论 1.63% 吻合。1 kHz 时点数 347，同样的偏移只有 0.004%，肉眼不可见 ——
实测 1 kHz 时读数稳定，也吻合。

**（2）抖动周期约 139 μs（拍频 7.2 kHz）**

采样的分数部分每周期前进 0.36 点，走完一整点需要 `1/0.36 ≈ 2.77` 个信号周期，
故抖动周期为 `2.77 / 20000 ≈ 139 μs`，对应拍频约 7.2 kHz。
实测：浮动确实以约 100 μs 量级的周期重复，示波器上表现为波形轻微"呼吸"。

**结论**：这两项"异常"都能由理论定量预测并与实测吻合，
因此判定为零阶保持 + 非相干采样的**固有结果**，不是设计缺陷。
这也反过来验证了采样率 347 kSPS 的计算是正确的 —— 如果实际采样率不是这个值，
抖动幅度（1.63%）和抖动周期（139 μs）都会对不上。

### 6.4 已评估但未实施的改善方案

| 方案 | 定量效果 | 为什么没做 |
|---|---|---|
| 提高 SCLK 到 20 MHz 上限 | 采样率 → 560 kSPS，20 kHz 时 26 点/周期 | 仍是台阶；面包板 + 杜邦线跑 20 MHz 风险大，收益小 |
| 一阶 RC 重构滤波（1 kΩ + 2.2 nF，fc = 72 kHz） | 对 327 kHz 镜像仅 −13 dB | **试过，实测对台阶几乎无改善**，已放弃 |
| 二阶 Sallen-Key（2.4 kΩ/2.4 kΩ/2.2 nF/1 nF，fc = 45 kHz） | 可达 −34 dB，叠加 ZOH 自身 −24 dB 后残余约 −58 dB | 需额外运放与焊接空间，本次未纳入 |

一阶 RC 的失败是有价值的记录：它说明**"加个滤波电容"这种经验做法在 300 kHz 量级不起作用**，
必须二阶以上。这条写进了技能包踩坑清单第 9 条。

## 7 交互比对（按键）

按键是本次调试中唯一出现"全局性故障"的部分，比对数据如下。

**原始电平（修复前，直接打进状态报文的 K 字段）**：

| 操作 | K 字段原始值 | 说明 |
|---|---|---|
| 不按键 | `1111` | 四路全高 |
| 按住 KEY_1 | `1110` | 最低位变 0 |
| 按住 KEY_2 | `1101` | — |
| 按住 KEY_3 | `1011` | — |
| 按住 KEY_4 | `0111` | 最高位变 0 |

这张表说明两件事：引脚映射正确（每个键对应唯一一位），
且按键是**低有效**（按下读到 0）。而当时的代码按"高有效"在顶层取了反，
于是空闲状态（原始 `1111`）被取反成全 0，被消抖模块判为"四个键全部按住"。

**故障表现与上表的对应关系**：

| 现象 | 由表中哪一行解释 |
|---|---|
| 上电后频率一路降到下限 100 Hz | 空闲被误判为按住 KEY_2 → 连发减频 |
| 相位值持续自行增加 | 空闲被误判为按住 KEY_3 → 连发加相位 |
| 方向自动变成"减" | 空闲被误判为按住 KEY_4 → 触发一次翻转 |
| 真正按键时反而"没反应" | 按下读到 0 → 取反后为 1 → 被当作"松开" |

一条实测数据同时解释了四个现象。修正两处后（XDC 的 `PULLTYPE` 改 `PULLUP`、
顶层去掉四处取反），状态报文空闲应为 `K=0000`，按住第 n 键第 n 位为 1。

**这是本次最值得复用的一条经验**：判断按键极性不要靠"空闲读高所以是悬空"这类推断，
应先把原始电平打出来，逐键按一遍拿到对照表，再定极性与映射。详见踩坑清单第 1 条。

## 8 串口报文比对

理论报文格式（36 字节 + 回车）：

```
F=01000 P=090 W=0 A=100 D=+ K=0000
```

字段与理论值对照见 `../report/综合与实现报告.md` 与设计报告表 A-2。
实测抓包记录见同目录 `串口报文样例.txt`。

实测确认的几点：

- 报文长度与时延符合理论：36 字节 × 10 bit ÷ 115200 ≈ **3.13 ms**，
  用秒表/日志时间戳观察，每行间隔与之相符。
- 每次参数变化（无论来自串口还是按键）都会自动回传一行 ——
  这是"按键操作也能在电脑上看到"的实现方式。
- `S1` 开启后每秒自动回传一行，用于调按键时不看屏幕也能确认状态。
